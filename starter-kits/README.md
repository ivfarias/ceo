# Starter Kits

This directory holds repository starters that complement the agent system in the root of `ceo`.

## Available kits

- [team-brain](team-brain/README.md) - A durable operating-memory repository for humans and AI agents, with `context/`, `inbox/`, `specs/`, and AI platform placeholders.

## How to think about it

- The root of `ceo` gives you the orchestration layer.
- `starter-kits/` gives you repository shapes that those agents can work inside.

If you want a full AI-first setup, use both.
