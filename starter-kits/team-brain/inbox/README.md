# inbox/

This is the landing zone for raw notes.

Put unstructured material here first:

- meeting notes
- daily updates
- transcripts
- screenshots converted to text
- ad hoc findings

## Naming convention

Use:

```text
yyyy-mm-dd-type-short-description.md
```

Examples:

- `2026-03-09-daily-growth.md`
- `2026-03-09-customer-call-acme.md`
- `2026-03-10-retro-product.md`

## Processing rule

Nothing should live here forever. Raw notes should move into structured documents, then the original file should move to `inbox/processed/`.
