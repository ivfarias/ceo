# context/

`context/` is the durable memory of the team.

Nothing in this folder should depend on a single sprint, campaign, or temporary initiative. If a document will still be useful after the current cycle ends, it belongs here.

## Keep here

- Operating rules
- OKRs and strategic priorities
- ICP and persona research
- Team ownership and working style notes
- Channel or workflow playbooks
- Append-only learnings

## Keep out of here

- Temporary experiments
- This-cycle plans
- Daily status changes
- One-off deliverables

Those belong in `specs/`.
