# Shared AI Assets

`.ai/` is the canonical shared layer for reusable AI assets in this repository.

Use it as the source of truth for:

- `skills/`
- `checklists/`
- `data/`
- `templates/`
- `utils/`

Platform-specific folders such as `.codex/`, `.claude/`, `.github/`, and `.gemini/` can mirror or adapt these assets for their runtime.

This copy intentionally excludes product- or company-specific reporting skills so the shared layer stays reusable.
